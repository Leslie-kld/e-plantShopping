# Paradise Nursery Shopping Application

## Project Description

Paradise Nursery is a React-based online plant shopping application.

The application allows users to:

- Browse houseplants by category
- View plant names, descriptions, images, and prices
- Add plants to a shopping cart
- View the number of items in the cart
- Increase and decrease plant quantities
- Remove plants from the cart
- View individual item totals
- View the overall cart total
- Continue shopping
- Use the checkout button

## Technologies Used

- React
- Vite
- Redux Toolkit
- React Redux
- React Router
- CSS

## Main Features

### Landing Page

The landing page displays the Paradise Nursery company name, background image, company description, and Get Started button.

### Product Listing

The product listing contains three plant categories with six unique plants in each category.

### Shopping Cart

The shopping cart allows users to manage plant quantities, remove items, and calculate the total cost.
